# 🌊 Stream API – Programação Funcional com Java

Este modulo integra o conjunto de exercícios práticos desenvolvidos durante o **Bootcamp CI&T – Backend com Java & AWS**, realizado na plataforma **DIO**.

O objetivo é dominar a **Stream API**, explorando a poderosa combinação de expressões lambda e as principais **Functional Interfaces** para manipular coleções de forma declarativa, eficiente e com código limpo, seguindo os padrões de desenvolvimento backend da CI&T.

---

## 📌 Funcionalidades e Conceitos Principais

Neste módulo, foram aplicadas as 5 principais interfaces funcionais do Java:

- **Consumer**: Processa elementos (ex: imprimir itens) sem retornar valores.
- **Supplier**: Fornece novos objetos ou dados de forma personalizada.
- **Function**: Transforma dados de um tipo para outro (map).
- **Predicate**: Realiza filtragens baseadas em condições lógicas (booleanas).
- **BinaryOperator**: Combina dois elementos para gerar um único resultado (redução).

---

## 💡 Desafios Implementados (20 Exercícios)

O repositório contém a resolução de **20 desafios práticos** focados na manipulação de fluxos de dados, abrangendo:
1. Ordenação e filtragem de coleções numéricas.
2. Cálculos estatísticos (média, soma, valores máximos e mínimos).
3. Identificação de padrões (números duplicados, primos e positivos).
4. Transformações de dados com o uso de `map` e `collect`.
5. Controle de fluxos condicionais e manipulação de `Optional`.

---

## 🧱 Regras de Negócio e Stream API
- **Imutabilidade**: Garantia de que as operações não modifiquem as fontes de dados originais.
- **Pipeline de Operações**: Estruturação de código através de operações intermediárias e terminais.
- **Legibilidade**: Substituição de estruturas de repetição complexas por sintaxe funcional concisa.
